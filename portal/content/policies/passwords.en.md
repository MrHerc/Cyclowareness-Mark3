# Password and Account Security Policy

Rules for passwords, two-step sign-in and the password manager on the Organisation's accounts.

## 1. Purpose
1.1. This policy sets out password, two-step sign-in and account rules that prevent work accounts from being taken over.

## 2. Scope
2.1. The policy applies to all employees, contractors and other persons with access to the Organisation's information systems.

## 3. Password requirements
3.1. A work password has at least 12 characters. A passphrase of several random words is recommended.

3.2. Passwords do not contain names, birth dates, the Organisation's name or sequences such as "123456" or "qwerty".

3.3. Every system has its own password. A work password is never reused for a personal service.

3.4. If a password may have leaked, change it at once and inform the IT security team.

## 4. Two-step sign-in
4.1. Two-step sign-in is turned on for every work account.

4.2. Never approve a sign-in request you did not start. It means someone else has your password: deny the request and tell IT.

4.3. One-time codes are never shared with anyone, IT staff included.

## 5. Password manager
5.1. Passwords are stored only in the password manager approved by the Organisation.

5.2. Passwords are not kept on paper, in spreadsheets, in messages or in unprotected browser storage.

## 6. No sharing
6.1. Passwords, codes and sign-in links are never shared. Shared accounts are used only with IT approval.

## 7. Code and configuration
7.1. Passwords, keys and tokens are never stored in plain text in source code, configuration files or documents. An approved secrets vault is used instead.

## 8. Violations
8.1. Breaking this policy may lead to disciplinary action. Report anything suspicious at once with the "Report something suspicious" button in the portal.
